# 🏢 极跃棋牌 · 企业级运营系统

一套**企业级棋牌游戏运营系统**，采用「后端服务 + Web 管理后台 + 桌面游戏客户端」三端架构，支持斗地主与内蒙麻将两大游戏，具备完整的商业化运营能力（RBAC 权限、审计、风控、财务、数据分析、配置中心）。

---

## 🏗 三端架构

```
┌─────────────────────────────────────────────────────────┐
│                    企业级三端体系                          │
├──────────────────┬──────────────────┬────────────────────┤
│  🌐 Web 管理后台  │  💻 桌面游戏客户端 │  ⚙️ 后端服务         │
│   admin-web       │   desktop         │   server           │
│   (运营人员用)     │   (玩家玩游戏)     │   (核心+管理API)    │
│   :5174           │   Electron exe    │   :3100            │
└──────────────────┴──────────────────┴────────────────────┘
                              │
                              ▼
                    JSON 持久化 / 可替换 MySQL+Redis
```

| 端 | 目录 | 面向 | 技术栈 |
| :--- | :--- | :--- | :--- |
| **Web 管理后台** | `admin-web/` | 运营/财务/管理员 | Vue3 + Vite + Element Plus + ECharts |
| **桌面游戏客户端** | `desktop/` | 玩家 | Electron + Vue3 |
| **后端服务** | `server/` | 三端共用 | Node.js + Express + Socket.IO + JWT |

> ⚠️ **网站 = 管理运营后台，软件 = 玩家游戏客户端**。玩家玩游戏请打开桌面客户端，Web 端仅用于运营管理。

## ✨ 企业级能力

### 🔐 RBAC 权限体系
- 5 种角色：超级管理员 / 运营 / 财务 / 客服 / 数据分析师
- 细粒度权限点（如 `user:ban`、`finance:grant`、`game:kick`）
- 管理员账号独立管理，路由级权限校验

### 📋 操作审计
- 所有后台管理动作追加写审计日志（操作人/角色/IP/对象/详情/时间）
- 审计统计与按动作筛选，不可篡改

### 🛡 风控中心
- 自动检测：异常金币变动、频繁破产补助、金币异常膨胀
- 风险分级（高/中/低）、处理状态流转、人工处置

### 📊 数据分析
- 对局/新用户/金币流动/营收趋势（近 N 天）
- 斗地主 vs 麻将游戏占比、用户活跃分层、留存率

### 💰 财务管理
- 金币/钻石总量、收支流水、今日收支、发放记录
- 财务权限隔离，发放全审计

### ⚙️ 配置中心
- 注册赠送/签到/破产补助/底分档位/倍数封顶/超时时间热配置
- 麻将规则开关（七对/飘胡/一炮多响）、维护模式

### 🎮 游戏管控
- 实时房间监控（游戏类型/模式/人数/状态）、强制解散
- 对局记录查询

## 🎴 游戏功能

### 斗地主（3 人）
完整牌型（单张/对子/三带/顺子/连对/飞机/四带二/炸弹/王炸）、叫抢地主、明牌、加倍、春天反春、倍数结算、AI 对战、托管。

## 🚀 快速启动

### 环境要求
- Node.js >= 18

### 1. 启动后端服务（三端共用）

```bash
cd server
npm install
PORT=3100 npm start
```

### 2. 启动 Web 管理后台

```bash
cd admin-web
npm install
npm run dev        # http://localhost:5174
```

### 3. 启动桌面游戏客户端

```bash
cd desktop
npm install
npm run dev        # 开发模式：Vite + Electron
npm run electron:build   # 打包 Windows 安装包 (exe)
```

### 一键启动
Windows 双击 `start.bat`，自动拉起三端服务。

## 🔌 企业级 API

| 模块 | 接口前缀 | 说明 |
| :--- | :--- | :--- |
| 管理登录 | `/api/admin/auth/login-admin` | RBAC 管理员登录 |
| RBAC | `/api/admin/rbac/*` | 角色/管理员管理 |
| 审计 | `/api/admin/audit/*` | 操作日志/统计 |
| 数据分析 | `/api/admin/analytics/*` | 趋势/留存/分层 |
| 风控 | `/api/admin/risk/*` | 事件扫描/处理 |
| 配置 | `/api/admin/config` | 系统配置热更新 |
| 实时房间 | `/api/admin/rooms/*` | 监控/解散 |
| 财务 | `/api/admin/finance/*` | 收支汇总 |

所有企业级接口需 `Authorization: Bearer <管理员token>`，并按 RBAC 权限点校验。
