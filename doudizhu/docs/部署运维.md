# 极跃棋牌 · 部署与运维手册

## 一、环境要求

- Node.js >= 18（推荐 20 LTS）
- npm >= 9
- Windows（桌面客户端打包 exe）/ 可选 Linux 服务器（仅后端）

## 二、部署步骤

### 后端服务
```bash
cd server
npm install --production
PORT=3100 npm start
```
生产环境建议用 PM2 守护：
```bash
pm2 start src/index.js --name jiyue-server -- env PORT=3100
pm2 save && pm2 startup
```

### Web 管理后台
```bash
cd admin-web
npm install
npm run build          # 产出 dist/
# 用 Nginx 托管 dist/，并反向代理 /api 与 /socket.io 到后端
```
Nginx 示例：
```nginx
server {
  listen 80;
  root /path/to/admin-web/dist;
  location / { try_files $uri $uri/ /index.html; }
  location /api { proxy_pass http://127.0.0.1:3100; }
  location /socket.io { proxy_pass http://127.0.0.1:3100; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }
}
```

### 桌面客户端
```bash
cd desktop
npm install
npm run electron:build   # 产出 release/ 下的 exe 安装包
```
分发 `release/` 里的安装程序给玩家。

## 三、配置管理

- 游戏参数：通过管理后台「配置中心」可视化修改，存 `server/data/systemConfig`。
- 环境变量：`PORT`（端口）、`JWT_SECRET`（签名密钥，生产必改）、`AI_THINK_MS`（AI 延迟）。
- 修改 `server/src/config/index.js` 可调整默认值。

## 四、数据备份

- 数据文件：`server/data/db.json`（含用户/金币/对局/审计/配置）。
- 建议定时备份：
```bash
cp server/data/db.json server/data/backup/db_$(date +%Y%m%d_%H%M%S).json
```
- 服务退出时自动 `store.flush()` 落盘，正常关停不会丢数据。

## 五、运维监控

- 健康检查：`GET http://localhost:3100/health`
- 管理后台「数据大屏」：在线人数、实时房间、今日对局、金币流水。
- 风控中心：异常事件实时告警与处置。
- 审计日志：所有管理操作可追溯。

## 六、安全建议

1. 生产环境务必修改 `JWT_SECRET` 与管理员默认密码。
2. 管理后台限制内网访问或加 IP 白名单。
3. 定期轮换管理员密码，按角色最小化授权。
4. 开启风控规则，关注大额金币流动事件。
