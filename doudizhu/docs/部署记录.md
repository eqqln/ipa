## 常用运维命令

```bash
# 查看后端状态
sudo pm2 list
sudo pm2 logs jiyue-server

# 重启后端
sudo pm2 restart jiyue-server

# 更新后端代码后
cd /www/wwwroot/game.shengka.net/server
sudo npm install --production
sudo pm2 restart jiyue-server

# 更新管理后台
# 本地 npm run build 后，上传 dist/* 到 /www/wwwroot/game.shengka.net/admin/

# Nginx 重载
sudo nginx -t && sudo nginx -s reload

# 数据备份
sudo cp /www/wwwroot/game.shengka.net/server/data/db.json \
  /www/wwwroot/game.shengka.net/server/data/db_$(date +%Y%m%d_%H%M).json
```

### 编译踩坑与修复链

1. MCP 工具未进索引 → 改用已授权的 fine-grained PAT，REST API 直推
2. 无建仓权限（403）→ 复用有写权限的 `eqqln/ipa`，源码放 `doudizhu/` 子目录隔离
3. 并发 PUT 触发 409 ref 竞争 → 改 Git Data API 原子提交（blob 并发、tree/commit/ref 串行）
4. CI `Rollup failed to resolve import "vue"` → vite.config.js 加 `resolve.modules`，并在 workflow 软链 `desktop/node_modules`
5. `Capacitor CLI requires NodeJS >=22` → setup-node 升 Node 22
6. `setup-android@v3` 装废弃 `tools` 包失败 → 删除该步，改用 runner 自带 SDK
7. `invalid source release: 21` → setup-java 升 JDK 21
8. iOS job 秒级 cancelled（macos-14 无法分配 runner）→ 拆分独立 workflow + 换 `macos-latest`（历史上成功编译过 6 次 IPA）
